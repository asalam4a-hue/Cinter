# نظام إدارة ومتابعة العقود

ثلاث نسخ كاملة بنفس الواجهة ونفس الشاشات، اختر ما يناسب استضافتك:

| المجلد | التقنية | قاعدة البيانات | مناسب لـ |
|---|---|---|---|
| `google-script/` | Google Apps Script | Google Sheets | بدون سيرفر، مجاني، يعمل من حساب Google |
| `php/` | PHP 7.4+ | SQLite (افتراضي) أو MySQL | استضافة cPanel / Apache عادية |
| `python/` | Python 3.9+ / Flask | SQLite | سيرفر خاص أو VPS أو جهاز داخل الشركة |

**الدخول الافتراضي:** المستخدم `admin` وكلمة المرور `admin123` — غيّرها فوراً من زر 🔑 أعلى الشاشة.

## التشغيل

### 1) Google Script
1. أنشئ Google Sheet جديداً ثم: Extensions ← Apps Script.
2. الصق محتوى `Code.gs` مكان الكود الموجود.
3. أضف ملف HTML (زر ＋ ← HTML) باسم **Index** بالضبط، والصق فيه محتوى `Index.html`.
4. (اختياري) Project Settings ← Show appsscript.json ثم الصق محتوى `appsscript.json`.
5. Deploy ← New deployment ← Web app ← Execute as: **Me** ← Who has access: حسب رغبتك ← Deploy، ثم وافق على الصلاحيات.
6. افتح رابط الـ Web app. أول تشغيل ينشئ الأوراق (Users, Contracts, History, Settings) تلقائياً.
> بعد أي تعديل على الكود: Deploy ← Manage deployments ← Edit ← New version.

### 2) PHP
1. ارفع محتوى مجلد `php/` إلى الاستضافة (يجب أن يكون المجلد قابلاً للكتابة ليُنشأ `data/`).
2. افتح `index.html` من المتصفح. لتجربة محلية: `cd php && php -S localhost:8000`.
3. لاستخدام MySQL: عدّل `config.php` (`driver` = `mysql` وبيانات الاتصال) وأنشئ قاعدة فارغة؛ الجداول تُنشأ تلقائياً.

### 3) Python
```bash
cd python
pip install -r requirements.txt
python app.py            # ثم افتح http://localhost:5000
```
للإنتاج: `pip install gunicorn && gunicorn -w 2 -b 0.0.0.0:5000 app:app` خلف Nginx مع HTTPS.

## الشاشات
- **الشاشة الرئيسية:** كروت KPI مضيئة ومتحركة (تفاعلية: ضغطة على كارت تفتح تفاصيله، وضغطة على مرحلة أو عمود في الرسم تصفّي اللوحة كلها)، مسار مراحل الإنتاج، ورسوم بيانية لكل الوحدات والعقود، مع فلتر بالوحدة والتاريخ.
- **العقود:** كل الحقول المطلوبة + تغيير المرحلة مع تاريخها + سجل مراحل كل عقد، وبحث وفلتر وترتيب لكل عمود.
- **متابعة العقود:** آخر مرحلة وتاريخها ونسبة الإنجاز والمتبقي للتسليم والتأخير.
- **التقارير:** تقارير العقود، الوحدات، المشروعات، اليوم، تاريخ محدد، مراحل الإنتاج — مع فلاتر برقم العقد والوحدة والمرحلة والفترة.
- **المستخدمون:** الاسم، اسم المستخدم، كلمة المرور (مشفّرة)، تاريخ الميلاد، تاريخ الإضافة، صورة، وصلاحيات تفصيلية لكل شاشة وتقرير وبند.
- **إدارة البرنامج:** اسم البرنامج، الشعار، قائمة الوحدات الإنتاجية، رقم واتساب افتراضي، وبيانات تجريبية.

## الصلاحيات والوحدات الإنتاجية
- كل مستخدم (غير مدير النظام) يُربط بوحدة إنتاجية أو أكثر من شاشة المستخدمين، ولا يرى ولا يعدّل إلا عقود وبيانات وحداته. التقييد مفروض في الخادم (عرض، إضافة، تعديل، تغيير مرحلة، حذف) وليس في الواجهة فقط.
- مستخدم بدون أي وحدة لا يرى أي عقد. مدير النظام يرى كل الوحدات.
- كل عقد يسجّل: أضيف بواسطة، آخر تعديل بواسطة، ووقت آخر تعديل. وكل تغيير مرحلة يُسجَّل في السجل باسم من نفّذه.
- تاريخ تغيير المرحلة تلقائي (تاريخ اليوم) عند تغيير المرحلة، ولا يُدخَل يدوياً. مرحلة الإنتاج قائمة منسدلة يمكن تغييرها مباشرة من جدول العقود.
- الضغط على أي تاريخ في الجداول يعرض قائمة بكل تواريخ العقد (إضافة، استلام، تسليم، وصول كل مرحلة)، وحقل بحث كل عمود تاريخ يعرض قائمة التواريخ الموجودة.
- الضغط على رقم العقد أو اسم المشروع يفتح تقريراً تفصيلياً (مراحل الإنتاج والتواريخ والمنفّذ) قابلاً للطباعة وPDF وExcel وواتس.

## الطباعة والتصدير والواتس
- كل شاشة وكل كارت/رسم/جدول له أزرار: 🖨️ طباعة، 📕 PDF، 📗 Excel، 💬 واتس (وتظهر حسب صلاحيات المستخدم).
- الرسوم تُطبع وتُصدَّر بألوان مناسبة للورق الأبيض، والشعار واسم البرنامج يظهران في رأس كل مطبوع.
- **واتس:** يفتح محادثة واتساب برسالة جاهزة تحتوي ملخص البيانات عبر رابط `wa.me`. واتساب لا يقبل إرفاق ملفات من رابط، فلإرسال ملف صدّر PDF/Excel ثم أرفقه يدوياً في المحادثة. (الإرسال التلقائي من الخادم يتطلب WhatsApp Business API وحساب مدفوع.)

## ملاحظات
- الواجهة تحمّل مكتبات Chart.js وSheetJS وhtml2pdf وخط Cairo من الإنترنت (CDN)، فيلزم اتصال بالإنترنت على جهاز المستخدم.
- الصور (الشعار وصور المستخدمين) تُصغَّر تلقائياً قبل الحفظ لتناسب قيود خلايا Google Sheets.
- لتعديل الواجهة: عدّل `src/frontend.html` ثم شغّل `python build.py` لتوليد الملفات الثلاثة.
- الصلاحيات تُفرض في الواجهة وفي الخادم معاً، ومن لا يملك صلاحية المدير لا يستطيع منح صلاحيات لا يملكها.

> التحديث من نسخة سابقة: قواعد البيانات القديمة تُرقّى تلقائياً (أعمدة المشروع والمنفّذ والوحدات تُضاف عند أول تشغيل). في Google Script الصق `Code.gs` و`Index.html` الجديدين ثم Deploy ← New version.
